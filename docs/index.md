## Where to start

- [What Acta is](/users/): the boards, the wiki and how they refer to each other.
- [Run your own instance](/developers/install): one container, SQLite, NAS-class hardware.
- [Connect an agent](/developers/mcp): the Model Context Protocol endpoint.

## MCP from day one

Every capability is a Model Context Protocol tool with the same fidelity the interface has. One call to orient, batched idempotent writes, delta reads and section-level document patches. See [the MCP endpoint](/developers/mcp).

## Humans and agents, one audit trail

One actor model covers people, agents and the system. Every mutation carries who did it and what caused it, so "an agent changed this" is a fact you can query rather than a guess. See [Concepts](/users/concepts).

## The plan as an order, not a wish

Declare that one card waits for another and Acta works out what can start now, what is downstream, and the chain that decides the finish. See [the sequence view](/users/working).

## Goals before cards

Name the outcome, link the cards from any space, and see two honest signals side by side: the owner's check-ins, and progress measured from the work. See [Goals](/users/goals).

## Yours to run

One container, SQLite, NAS-class hardware. Email codes, or bring your own provider over standard OpenID Connect. No seat count, no phone-home. See [Install](/developers/install).

## A way out of what you have

Importers for Trello and Confluence that carry comments, attachments, history and cross-references, and tell you precisely what they could not. See [Migrate](/developers/migrate-trello).

## Boards and wiki in one place

Plans cite decisions and decisions cite the cards that implemented them. References resolve both ways and survive a card being moved or renamed. See [the model](/users/concepts).
